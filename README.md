# dotfiles

My macOS configs, one directory per tool, symlinked into place by `./install.sh`.
See [AGENTS.md](AGENTS.md) for the layout and conventions, and
[TERMINAL.md](TERMINAL.md) for the terminal workflow playbook.

```bash
git clone https://github.com/tharshikan/dotfiles.git ~/Projects/Personal/dotfiles
cd ~/Projects/Personal/dotfiles && ./install.sh
```
